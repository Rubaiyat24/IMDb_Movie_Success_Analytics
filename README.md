# IMDb Movie Success Analytics

## Project Overview
This project analyzes movie performance using IMDb/TMDB movie datasets.

The project combines:
- SQL
- Python
- Data Visualization
- Machine Learning
- Business Analytics

## Business Questions
1. Which genres have the highest ratings?
2. Which movies generated the highest revenue?
3. Do longer movies receive higher ratings?
4. Which genres generate the highest revenue?
5. Which genres receive the highest ratings?
6. How have movie ratings changed over time?
7. Which movies generated the highest revenue?
8. Can we predict movie success using machine learning?

## Tools Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- SQL

## Dataset
IMDb/TMDB Movie Dataset from Kaggle.
